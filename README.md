# PDF Consent Form Tool
https://hy030401.github.io/PDF-editing-and-printing/



A client-side web application for filling, signing, and downloading fixed-layout PDF consent forms directly in the browser.

# Features

Fixed-position text, date, checkbox, and radio inputs aligned to the original PDF

Handwritten signature capture using canvas

Local PDF generation, no server, no uploads

Mobile-friendly preview and instant download

Custom filename based on user input

# Tech Stack

PDF.js 

pdf-lib

signature_pad

HTML / CSS / JavaScript

GitHub Pages 

# Privacy

All data is processed locally in the browser.
No form data is transmitted or stored on any server.

# Usage

Open the page

Fill in the form and sign

Download the generated PDF

# Notes

Used in a real business setting for customer consent form signing.
Designed as a lightweight, privacy-friendly alternative to server-based form systems.
